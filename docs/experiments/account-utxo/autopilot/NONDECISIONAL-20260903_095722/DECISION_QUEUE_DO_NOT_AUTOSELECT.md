## Mandatory paired branching rule

If a branch changes the external semantic case, evidence identity changes. If a
capability belongs to the common case, both candidates receive the same
availability assumption. If equivalent availability depends on candidate
architecture, run symmetric explicit branches or mark the claim **ASSUMPTION
DEPENDENT**. Candidate-native records, sources, inputs, outputs, credentials,
signatures, proofs, reads, or writes remain descriptive until a reviewed neutral
unit maps them.

## Decision package prerequisites

An owner-facing future decision package should contain alternatives, inherited
constraints, evidence by class, uncertainty, security vetoes, migration and
historical consequences, symmetry review, and unresolved dependencies. This
pack does not populate a recommendation column.
